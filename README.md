# OtimizaHub

Site institucional e landing page da OtimizaHub, desenvolvido com React, TanStack Router/Start, Vite e componentes de interface modernos.

## Projeto

A OtimizaHub atua com soluções de presença digital para micro e pequenas empresas, incluindo:

- Perfil da Empresa no Google;
- Landing pages profissionais;
- Páginas de vendas;
- Meta Ads;
- Consultoria e soluções digitais personalizadas.

## Estrutura atual

- `src/`: aplicação React/TanStack atual.
- `src/routes/`: rotas da aplicação.
- `src/content/otimizahub.html`: conteúdo e composição principal da página.
- `src/styles.css`: estilos e identidade visual.
- `src/assets/`: imagens e recursos visuais utilizados pela aplicação.
- `vite.config.ts`: configuração do Vite/TanStack Start.
- `package.json`: dependências e scripts do projeto.

## Desenvolvimento

Instale as dependências e execute o ambiente de desenvolvimento conforme os scripts definidos em `package.json`.

O projeto está conectado ao fluxo de desenvolvimento do Lovable por meio deste repositório GitHub. A branch principal é `main`.

Não armazene senhas, tokens, chaves privadas ou outras credenciais neste repositório. As configurações de segurança devem ser mantidas compatíveis com os recursos efetivamente utilizados pela aplicação e pela hospedagem.
